# Onshape

> Onshape is a cloud-native CAD and product data management (PDM) platform (part of PTC) that runs entirely in the browser. Its REST API exposes documents, part studios, assemblies, drawings, translations/imports-exports, release management, metadata, and webhooks over HTTPS.

## APIs
- [Onshape REST API Explorer](https://cad.onshape.com/glassworks/explorer/): Interactive API reference (Glassworks).
- [OpenAPI spec](https://cad.onshape.com/api/openapi): OpenAPI 3.0.1, base https://cad.onshape.com/api/v16.
